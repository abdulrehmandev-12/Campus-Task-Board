# Campus Task Board

A simple React + Vite project for Assignment #1 (CLO-1).

## Included requirements

- `useState` stores 3 initial tasks.
- Tasks contain `id`, `title`, and `category`.
- Tasks are rendered with `.map()`.
- Every task has a unique React `key`.
- Reusable `TaskCard` component receives task data through props.
- New tasks can be added without refreshing the page.
- `useEffect` logs the required message and total task count whenever tasks change.
- Git/GitHub ready.

## Run

```bash
npm install
npm run dev
```
